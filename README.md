## Wat ik gebouwd heb

Het meeste van mijn werk is maatwerk voor opdrachtgevers en daarom niet publiek. Een greep:

| Project | Wat het doet | Stack |
|---|---|---|
| **Urenregistratie & verlofbeheer** | Vervangt een verouderd registratiesysteem; leest medewerkers/projecten uit de Firebird-database van Syntess Atrium, slaat workflows en notificaties op in PostgreSQL, met goedkeuringsflows en rapportages | .NET 8, Next.js, Firebird, PostgreSQL (Neon), GitHub Actions |
| **Financieel dashboard op Syntess Atrium** | Read-only BI-dashboard met drill-down van jaaroverzicht tot factuurregel, direct op de ERP-database | Node/Fastify, node-firebird, Next.js 16, TanStack Query, shadcn/ui |
| **Ticketing & tijdregistratie-platform** | Eigen helpdesk/ticketingsysteem met urenregistratie, in productie bij een IT-dienstverlener | Next.js, TypeScript, PostgreSQL |
| **Clockd v2** | Middleware-dashboard dat tijdregistraties synchroniseert naar Syntess Atrium | Next.js, TypeScript |
| **Bench provisioning tool** | Desktop-tool voor gestandaardiseerde inrichting van werkplekken | C# WinForms |
| **Klantwebsites** | Sites en portalen voor installateurs, bouwbedrijven en zorgorganisaties | Next.js, Astro, Sanity/Keystatic |
